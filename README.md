# 好牌多抓 · Good Card Replica (STS2 mod)

《杀戮尖塔2》模组：新增遗物「好牌多抓」，用【制模】把不想要的卡牌奖励转成充能，
攒满后用【取样】从自己卡组里按权重复制一张已有卡。

- 目标游戏版本：v0.113.1（Steam 默认分支）
- 运行时：Godot 4 + 游戏自带 mod 加载器（无需 BepInEx / 无需前置框架即可运行）
- 状态：beta 开发中

## 设计

| 概念 | 行为 |
|---|---|
| 【制模】 | 卡牌奖励屏上的额外按钮：放弃本次卡牌奖励，遗物 +1 层充能 |
| 【取样】 | 充能达阈值 a（默认 3）后，同一按钮变为【取样】：清空充能，从卡组按权重抽 b（默认 2）张，选 1 张获得一张干净副本（无升级、无附魔） |
| 权重 | 白 c=6 / 蓝 d=4 / 金 e=2 / 无色 f=1 / 诅咒 g=3（均可配置） |

设计约束：v0.113.1 的 `CardReward` 只支持最多 2 个 alternative 按钮，且手工指定卡牌的
`CardReward` 无法序列化（`CardReward.ToSerializable()` 会抛异常），因此不使用独立奖励行，
而是复用原版 alternative 机制（同 PaelsWing 的 SACRIFICE）。
